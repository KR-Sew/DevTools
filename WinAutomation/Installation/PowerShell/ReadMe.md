## ✅ These are scripts and descriptions for installing and updating **PowerShell** engine

 Extend the PowerShell script to:

- [Set-PwshVersion.ps1](./Set-PwshVersion.ps1)
  - This script serves to set the latest installed **Powershell** version as a default **Powershell** engine
- [Update-Powershell.txt](./Update-Powershell.txt)
  - This file contains **Powershell** script that can be used for `Copy` and `Paste` to update **Powershell** being in `termninal` session.
